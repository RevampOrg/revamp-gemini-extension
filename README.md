# Revamp Website Builder for Gemini CLI

Create or redesign a website, build a web app, and keep refining it with Revamp from Gemini CLI. Describe what you want in ordinary language; Revamp creates a project you can preview and continue improving in the same conversation.

## Install

```sh
gemini extensions install https://github.com/RevampOrg/revamp-gemini-extension
```

Connect your Revamp account when Gemini CLI prompts you. If the connection needs to be started manually, run `/mcp auth revamp` inside Gemini CLI. This extension connects to Revamp's hosted MCP server. It contains no account credentials and runs no local server.

## Try it

- “Create a modern website for my law firm with practice areas, attorney profiles, and consultation requests.”
- “Redesign my website at [public URL] with a clearer message and an easier path to book a consultation.”
- “Build a client portal where customers can sign in and see their project updates.”
- “Show my recent Revamp projects.”

Revamp can start a project without opening a browser tab. Gemini CLI can check progress, show the latest available preview, and request changes to the same project. A preview is not a published website.

Learn more at [revamp.dev](https://revamp.dev/). For help, visit [Revamp support](https://revamp.dev/support/).
